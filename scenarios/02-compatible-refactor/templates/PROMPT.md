# 호환성 유지 리팩터링

## 목표

__MODULE_A__와 __MODULE_B__의 중복된 출력 조립 로직을 __SHARED_MODULE__로 옮긴다.
`refactor-contract.md`의 기존 CLI 옵션·기본값·JSON 필드와 타입·종료 코드·stdout/stderr
동작을 유지한다. 각 반복에서는 BACKLOG의 한 작업만 수행한다.

## 제약과 검증

- 허용 경로: __ALLOWED_PATHS__
- 수정 금지 경로: __OFF_LIMITS_PATHS__
- 새로운 의존성이나 공개 인터페이스 변경은 이번 범위 밖이다.
- 매 작업 뒤 `__TEST_COMMAND__`를 실행하고 수집된 테스트 수·종료 코드·출력을 남긴다.
- 실패한 기대값을 새 동작에 맞춰 갱신하지 않는다.
- 테스트를 실행하지 못하면 이유를 fix_plan에 적고 검증된 것으로 보고하지 않는다.
- 기준 계약의 예외가 필요하면 구현을 확대하지 말고 판단이 필요한 사항을 보고한다.

## 완료 기준

계약 검사가 통과하고 두 모듈이 공통 구현을 사용하며, 전체 회귀 검사와 리뷰 지적이
해결되어야 한다. 실제 증거를 확인한 뒤 fix_plan에 작업 내용과 남은 사항을 기록한다.
