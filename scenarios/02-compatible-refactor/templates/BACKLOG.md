# 호환성 유지 리팩터링 작업

시작 전 refactor-contract.md의 계약 검사를 기존 구현에서 통과시킨다.
각 행은 한 반복의 작업이며, 경로와 테스트 명령을 실제 값으로 채운다.

- [ ] __SHARED_MODULE__에 기존 출력 조립 로직을 추출하고 독립 단위 검사를 추가한다. 기존 호출부는 유지한다. 검증: __TEST_COMMAND__.
- [ ] __MODULE_A__만 공통 구현으로 전환한다. 해당 CLI의 정상·오류·빈 결과 계약과 전체 회귀를 확인한다. 검증: __TEST_COMMAND__.
- [ ] __MODULE_B__를 공통 구현으로 전환하고 더 이상 쓰이지 않는 중복 코드만 제거한다. 양쪽 계약과 전체 회귀를 확인한다. 검증: __TEST_COMMAND__.
