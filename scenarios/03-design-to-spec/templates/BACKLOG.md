# 보고서 생성 명세 구현 작업

§ 번호는 spec.md와 일치시킨다. 각 작업에서 필요한 검사도 함께 추가·실행한다.
최대 3회는 최초 시도의 상한이며, 실패 시 모든 작업이 완료된다는 뜻이 아니다.

- [ ] (§2, §3.1, §5.1) 선택한 설계의 정상 생성 경로와 공개 인터페이스를 구현하고 정상 경로 검사를 통과시킨다.
- [ ] (§3.2, §5.2) 실패·중복·중단 처리를 구현하고 정해진 경계 조건 검사를 통과시킨다.
- [ ] (§2, §4, §5.1, §5.2) 기존 호출자와의 호환성을 통합 검증하고 전체 회귀를 실행한다. 발견한 명세 범위 내 결함을 수정한다.
